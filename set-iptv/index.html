Kurz erklärt

SET IPTV ist ein IPTV Player für Samsung, LG und Android. Die App zeigt beim Start eine MAC-Adresse. Auf der Upload-Seite der offiziellen SET-IPTV-Website tragen Sie diese MAC-Adresse und Ihren M3U-Link ein. Nach dem Neustart der App sind Sender und EPG da. Nach der Testphase wird die App per einmaliger Gebühr aktiviert.

Was ist SET IPTV?

SET IPTV ist eine Abspiel-App, die sich besonders auf Samsung- und LG-Fernsehern bewährt hat. Sie zeigt eine klassische Senderliste mit Programmführer und unterstützt Filme und Serien aus M3U-Listen. Die Verwaltung erfolgt über die Website des Entwicklers.

SET IPTV einrichten

  1. SET IPTV im App-Store des Fernsehers suchen und installieren.
  2. App öffnen und die MAC-Adresse notieren.
  3. Auf der offiziellen SET-IPTV-Website die Seite zum Hochladen der Playlist öffnen.
  4. MAC-Adresse und M3U-Link eingeben, optional eine EPG-Adresse.
  5. Speichern, App am Fernseher neu starten – fertig.

Direkt auf Ihrem Gerät ausprobieren: Testen Sie IPTV Kanal kostenlos und ohne Zahlungsdaten. Unser Support hilft per E-Mail oder WhatsApp bei der Einrichtung.

Testphase und Aktivierung

Nach einer Testphase verlangt der Entwickler eine Aktivierungsgebühr, die über die Website mit der MAC-Adresse bezahlt wird. Den aktuellen Betrag und die Laufzeit der Aktivierung finden Sie dort. Die Aktivierung gilt für das jeweilige Gerät.

SET IPTV auf Samsung, LG und Android

Auf Samsung-Fernsehern mit Tizen und LG-Fernsehern mit webOS installieren Sie SET IPTV aus dem jeweiligen App-Store. Die Verfügbarkeit kann je nach Modelljahr und Region schwanken. Auf Android-Geräten läuft die App ebenfalls, dort gibt es mit TiviMate und IPTV Smarters Pro aber komfortablere Alternativen.

Die Aktivierung ist an die MAC-Adresse des Geräts gebunden. Wechseln Sie den Fernseher, müssen Sie die App auf dem neuen Gerät erneut aktivieren und die Playlist mit der neuen MAC-Adresse hochladen.

FAQ

Häufige Fragen

Ist SET IPTV kostenlos?

SET IPTV bietet eine Testphase. Danach wird eine Aktivierungsgebühr an den Entwickler fällig. Ihr IPTV-Abo mit den Sendern ist davon unabhängig.

Wo finde ich die MAC-Adresse in SET IPTV?

Die MAC-Adresse wird beim Start der App auf dem Bildschirm angezeigt, meist zusammen mit dem Aktivierungsstatus.

Warum lädt SET IPTV meine Playlist nicht?

Prüfen Sie, ob die MAC-Adresse exakt stimmt und der M3U-Link im Browser funktioniert. Danach die App vollständig neu starten.

Unterstützt SET IPTV EPG?

Ja. Der Programmführer wird aus der Playlist oder einer separat hinterlegten EPG-Adresse geladen.

Muss ich SET IPTV bei einem neuen Fernseher neu aktivieren?

Ja. Die Aktivierung gilt für die MAC-Adresse eines Geräts. Auf einem neuen Fernseher aktivieren Sie die App erneut und laden die Playlist mit der neuen MAC-Adresse hoch.
